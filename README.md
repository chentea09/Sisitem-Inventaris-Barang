# Sisitem-Inventaris-Barang
Web Inventaris Barang untuk menyimpan dan memudahkan pengguna melihat atau mengedit barang di penyimpanan inventaris

# Sistem Inventaris Barang

Projek UTS berupa aplikasi inventaris barang berbasis web yang dibuat untuk mempermudah pengelolaan data barang.

## Teknologi yang Digunakan

* PHP
* MySQL/MariaDB
* HTML dan CSS
* Laragon

## Fitur Aplikasi

* Menampilkan data inventaris barang
* Menambah, mengedit, dan menghapus data barang
* Mencari data barang
* Menampilkan total barang dan statistik kondisi barang

## Cara Menjalankan

1. Simpan folder `inventaris` di `C:\laragon\www`.
2. Jalankan Laragon dan aktifkan Apache serta MySQL/MariaDB.
3. Impor file `db_inventaris.sql` melalui phpMyAdmin.
4. Sesuaikan konfigurasi database pada `koneksi.php`.
5. Buka `http://localhost/inventaris/` melalui browser.

## Tujuan

Memenuhi tugas Ujian Tengah Semester (UTS) dengan menerapkan operasi CRUD menggunakan PHP dan MySQL.
